# telluswhere

Tell us where -style data collection sites.

Pull requests welcome.


## Installation

A (mostly) automated installation script is at:
https://github.com/cyclestreets/cyclestreets-setup/tree/master/install-telluswhere

The GUI specific to the site should be symlinked into the /style/ directory.
A template for this is provided, though (as of May 2020) this is not complete in showing all available HTML/CSS hooks that the Telluswhere library provides.


## Example sites

* [Widen My Path](https://www.widenmypath.com/)
* [London Cycling Data](https://www.londoncyclingdata.org.uk/)
* [Urban Cycle Parking](https://www.urbancycleparking.org.uk/)
* [Cycling Sorted](https://www.cyclingsorted.org/)
